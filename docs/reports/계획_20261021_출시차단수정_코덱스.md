# 출시 차단 문제 수정 계획

사용자 승인: 남은 작업과 추천 추가 작업 진행. 현재 앱·API 수정, 기존 스토어 문서 통합, 검사·빌드·커밋·푸시·운영 기록을 진행한다. 계정 본인확인과 실결제는 별도로 남긴다.

## 완료 조건

- [x] 스토어 문서 6개 진행분을 기존 커밋 그대로 통합하고 완료 이력 보존.
- [x] 현재 SDK로 패키지 설정을 재생성하고 기존 17개 테스트 및 새 회귀 검사 통과.
- [x] Google 로그인·사용자 귀속 검증 연결, 영수증 미검증·중복 충전 차단 검사 통과.
- [x] 구매 실패·재시작의 미완료 영수증 보존과 검증 뒤 스토어 완료 처리 검사 통과.
- [x] 쿨타임 계약 및 생성 시 서버 검사, 히스토리 큐 동시 갱신·중복 검사 통과.
- [x] 최소 글자 크기·고대비·로컬 LINESeedKR·앱 버전/히스토리 적용 확인.
- [x] 정적 분석·새 Android release AAB 빌드와 산출물 크기·해시 확인.
- [x] 구현 커밋·원격 푸시 재조회, 사용한 워크트리 상태 확인, 아웃라인 위키/작업로그와 인계 저장·재조회.

## 외부 조건과 사용자 확인

- Google Play 본인확인, 상품·테스터·Publisher API 권한, 실제 결제/복원과 기기 알림은 계정·실기기 확인이 필요하다.
- 운영 배포는 기존 서비스 설정·연동 앱 영향과 복구 수단을 확인한 뒤 진행한다. 미설정된 검증은 성공으로 우회하지 않는다.
- 랜딩페이지 신설·변경은 완료 시 구체 결과를 바탕으로 별도 질문한다.

Ruflo는 현재 도구 목록에 없어 사용할 수 없다. 기존 수정 파일과 타 세션 자원은 보존한다.

구현·로컬 검증 항목은 통과했다. 실제 계정·실결제·PostgreSQL 동시성·운영 배포는 위 외부 조건으로 남으며 완료로 처리하지 않는다. 서버는 초안 PR에 보존하고 의도적 중지 상태를 유지한다.
